# Quick Start Guide

## 🎯 Get Started in 3 Steps

### 1. Install Dependencies
```bash
cd campaign-onboarding-standalone
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Open in Browser
Navigate to **http://localhost:3000**

---

## ✨ What You'll See

The application starts with a **Login Screen** that kicks off a multi-step onboarding flow:

1. **Login** - Sign in interface with email and OAuth options
2. **Team Size** - Select your team size
3. **AI Teammate Feature** - Learn about AI capabilities
4. **Chat Hub** - Discover multi-model AI chat
5. **Workflows** - Explore automation features
6. **Final CTA** - Call to action screen
7. **Welcome** - Campaign generator welcome
8. **Input** - Enter product details
9. **Generating** - AI processing animation
10. **Results** - View generated campaign assets

## 🔧 Development Tips

### Hot Reload
- Changes to code automatically reload the browser
- No need to restart the server

### Component Library
- All UI components are in `src/components/ui/`
- Easily customizable via Tailwind classes
- Supports dark mode (CSS variables)

### Customize
- **Colors**: Edit `src/app/globals.css`
- **Content**: Modify `src/app/page.tsx`
- **Styles**: Use Tailwind utility classes
